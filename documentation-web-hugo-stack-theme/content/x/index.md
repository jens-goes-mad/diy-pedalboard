## Hardware

### Microcontroller

The blog uses two microcontrollers. [Arduino Nano](/arduino) for simplicity and ESP32-S3 for performance and 
providing USB class compliant interface. You can find [pin out](/electronics/mcu#pin-out) of both. 
I scratch [microcontroller basics](/arduino/avr), [opcodes and instructions](/arduino/avr/instruction-basics) 
and remember the [good old times](/design/electronic_circuits). I simulate circuits without soldering using 
[online tools](/design/electronic_circuits#circuit-simulation)

## Tools

### HUGO

[HUGO](https://gohugo.io/) is a template engine written in GO and creates static WebSites 
from [Markdown](https://www.markdownguide.org/basic-syntax/). 
In combination with [StackTheme](https://github.com/CaiJimmy/hugo-theme-stack) it builds the backbone of my blog.
Needless to say, I added some [extensions](https://github.com/jens-goes-mad/diy-pedalboard/tree/master/documentation-web-hugo-stack-theme) 
to the menu system and sidebar.
